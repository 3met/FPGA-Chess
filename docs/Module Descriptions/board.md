
### Board Ports

| Direction | Port Name         | Description                                                                                             |
| --------- | ----------------- | ------------------------------------------------------------------------------------------------------- |
| Input     | `board_operation` | Operation code for what the board should do. Port only read when `ready` is asserted.                   |
| Input     | `data_in`         | Tile data to be written to tile.                                                                        |
| Input     | `move`            | A move for the board to make.                                                                           |
| Input     | `in_search`       | Indicates whether operations should be treated like part of a tree search or a non-search board update. |
| Output    | `ready`           | Indicates ready for next operation.                                                                     |
| Output    | `illegal_board`   | Indicates the board position is illegal.                                                                |
| Output    | `best_move`       | Outputs best move after "Get Best Move" operation.                                                      |
| Output    | `board_score`     | Outputs board positional score after "Get Board Score" operation.                                       |
| Output    | `tile_data`       | Outputs tile data after "Get Tile Data" operation.                                                      |
